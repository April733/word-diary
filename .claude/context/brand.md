# Aikoread 品牌规范

产品名：**Aikoread / 爱可悦读**  
吉祥物原型：**科莫多巨蜥（Komodo）**

## Logo

权威 logo：`logo.png` / `logo-circle.png`（看书巨蜥，透明底 / 圆形）  
Favicon：`logo-circle-64.png`  
登录卡片与首页顶栏使用圆形 logo。

## 登录布局（硬性）

插画 **只做背景**（半透明、不占栏），登录卡片居中。  
禁止「左侧主图 + 右侧表单」并排布局。

Logo 用圆形 `logo-circle-64.png` 放在卡片标题旁。


## 全局背景

`App.vue` 在非登录、非阅读器页提供：奶油底 `#F6F0E6` + `#A8B59F` 弧形色块 + 淡可爱巨蜥。  
阅读器关闭装饰以免干扰正文。
