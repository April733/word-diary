一、业务概述

1.1 核心层级

用户 → 单词本 → 单词 → 艾宾浩斯学习计划 → 每日背诵/复习

1.2 核心原则

① 纯私有：所有单词、单词本、学习进度全绑定用户 ID，无公共共享库。

② 没学过的词绝不出现：只有用户手动录入的单词才进入学习计划，未录入生词全程隐身。

③ 配置表驱动：复习间隔天数、学习状态由配置表统一管理，改表不改代码。

1.3 业务流转总览

注册登录 → 创建单词本 → 录入单词 → 自动生成学习计划 → 初次学习 → 每日复习 → 熟记结业

三、艾宾浩斯核心逻辑

3.1 状态机

0
未学习
1
已初学
2
复习中
3
已熟记 ✓
4
遗忘重学
0 未学习→ 1 已初学→ 2 复习中→ 3 已熟记
2 复习中→ 4 遗忘重学→ 0 未学习（重新开始）

3.2 核心公式

next_review_time = first_study_time + sys_ebbinghaus_node[current_level].day_interval

注意：day_interval 是距离首次学习日期的天数，不是距上一次复习的天数。

3.3 完整生命周期示例（单词 "apple"，7月5日录入）

日期事件statuslevelnext_review_time计算
7/5录入，自动建计划00NULL—
7/5初次学习完成117/67/5 + 1天
7/6第1次复习 ✓227/77/5 + 2天
7/7第2次复习 ✓237/97/5 + 4天
7/9第3次复习 ✓247/127/5 + 7天
7/12第4次复习 ✓257/207/5 + 15天
7/20第5次复习 ✓268/47/5 + 30天
8/4第6次复习 ✓ 熟记！36—到达最高层级，结业

3.4 遗忘流程

假设 7/12 复习时没记住：

  • learn_status → 4（遗忘重学）
  • current_level → 0（归零）
  • next_review_time → NULL（清空）
  • 单词重新出现在「待新学」列表，从头开始新一轮艾宾浩斯周期
  • first_study_time 和 review_times 保留，不重置（用于统计）

3.5 每日推送规则

系统每天筛选 wd_learn_plan 中满足以下条件的记录：

  • user_id = 当前用户
  • learn_status != 3（排除已熟记）
  • next_review_time = 今天

→ 推送到「今日复习」列表，前端展示为背诵卡片。

4.3 分层职责

层职责规则
Controller接收请求、参数校验、调用 Service、返回 R<T>不写业务逻辑
Service核心业务逻辑、事务管理一个 Service 可调用多个 Mapper
Mapper数据库 CRUD只做数据访问，不写业务
Entity数据库表映射纯 POJO，不暴露给前端
DTO接口入参/出参与 Entity 分离

4.4 统一响应体

{
  "code": 200,
  "message": "success",
  "data": { ... }
}

4.5 StudyService 核心方法

方法触发场景核心操作
generatePlan() 单词录入后自动调用 插入 wd_learn_plan，status=0, level=0
firstLearn() 用户完成初次学习 status→1, level→1, 记录 first_study_time, 计算 next_review_time
reviewRemember() 复习记住 review_times+1, level+1, 查配置表更新 next_review_time, 达最高层级→status=3
reviewForget() 复习遗忘 status→4, level→0, next_review_time=NULL
getTodayTasks() 查询今日待复习 筛选 next_review_time=今天 AND status!=3
getNewWords() 查询待新学单词 筛选 status=0

七、页面与路由规划

路由页面功能需要登录

/dashboardDashboardView仪表盘：今日待学数、累计统计、快捷入口是

7.1 核心页面：StudyView 交互流程

布局：顶部 Tab 切换「待新学」/「今日复习」

待新学：

  • 卡片正面显示单词原型 + 音标
  • 点击翻转 → 背面显示释义 + 例句 + 词根词缀
  • 点击「已掌握」→ 调用 POST /api/study/first-learn/{planId}

今日复习：

  • 卡片正面只显示单词，用户先回忆
  • 点击翻转查看释义
  • 两个按钮：「记住了」→ reviewRemember / 「没记住」→ reviewForget
